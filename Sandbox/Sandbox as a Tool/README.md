# Sandbox as a Tool

[返回 Sandbox 总索引](../README.md) · [返回论文库](../../README.md)

本目录按服务用途归类：沙箱主要作为 Agent 调用的代码、命令、工具执行或环境准备能力。长期状态或支持回滚并不自动使其变为完整 rollout 托管平台。

| 论文 | 归类依据 |
| --- | --- |
| [Readie](2026_Readie_2611.22171.pdf) | 主要优化 Agent 生成代码的执行环境启动与快照准备，沙箱作为代码执行工具服务。依据：PDF 第 1 页摘要。 |
| [Planarian](2026_Planarian_2609.35366.pdf) | 主要通过工具路由管理本地执行副作用和远端 MCP 状态，恢复后将状态信息交回 Harness。虽支持长期状态与分支，本库按其工具执行/状态管理接口归类。依据：PDF 第 2 页说明、第 4 页图 2。 |
| [HerAgent](2026_HerAgent_2611.18443.pdf) | 主要由环境构建 Agent 调用 Docker 执行、验证和回退安装 block，产出可重放环境；本库按被调用的环境准备工具归类，不将其视为承载 RL rollout 的托管平台。依据：PDF 第 3–4 页 §III 及作者仓库 Core Loop。 |
| [Sandlock](2026_Sandlock_2605.26298.pdf) | 主要隔离 Agent 调用的命令、脚本、插件及子进程，关注工具调用的权限与启动成本。依据：PDF 第 1–2 页 §1/§2.1。 |
| [SpecBox](2026_SpecBox_2607.23933.pdf) | 主要根据流式生成中的工具意图预热外部工具沙箱，优化工具服务的资源开销和尾延迟。依据：PDF 第 1 页摘要、第 3–4 页运行时与图 3。 |

完整题名、发表状态、代码、Harness 物理部署和实验建议见 [Sandbox 总索引](../README.md)。两类通用的 Crab、DeltaBox 保留上层，不重复复制。
